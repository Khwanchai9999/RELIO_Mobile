# RELIO QA 0.9.0+39 — Automatic Text Relay candidate

- เพิ่มโหมด Text: เส้นทางอัตโนมัติ, ส่งตรงเท่านั้น และ QA บังคับผ่านเครื่องกลาง
- QA Chat บันทึก SQLite ก่อนตรวจเส้นทาง; อัตโนมัติเลือก Direct ก่อนและตรวจ B–C สดเมื่อจำเป็น
- เลือกตัวกลางแบบคงที่ครั้งละเครื่อง จำกัดสอง hops ใช้ซองเดิมเมื่อ retry
- QA Text รับผลปลายทางย้อน C → B → A; stored ACK ยังเป็นเพียงรับฝาก
- Log แยกตามรหัสข้อมูล เรียงตามเวลาและแสดงชื่อ peer ในเครื่อง
- Retry เฉพาะ foreground และจำกัดจำนวนครั้ง; delivered ไม่ย้อนกลับเป็น sent
- Media, SOS, Cloud และ DEV/PROD ไม่เปิด automatic routing
- ไม่มี migration และไม่ล้างข้อมูล

ข้อจำกัด: final receipt เป็นรายงานจาก peer ที่ยืนยันตัวตน ไม่ใช่ end-to-end cryptographic signature; ไม่ใช่ background mesh และไม่ relay media การเปลี่ยนโหมดมีผลกับข้อความใหม่ ข้อความที่เริ่ม Relay แล้วคงเส้นทางเดิม
