# RELIO QA 0.9.0+41 — durable receipt recovery

- คง Auth recovery และ QA-only Text forwarding hold จาก Build 40
- แก้ ACK ปลายทางหายเมื่อ upstream ไม่เชื่อมต่อ: อ่านผล delivered ที่ยังอยู่ใน TTL จาก SQLite และส่งกลับเมื่อ upstream พร้อม โดยไม่ส่ง payload ใหม่
- จำกัดการกู้ ACK นี้ไว้ใน TEST Text เท่านั้น ไม่เปลี่ยน SOS, schema, identity gate หรือการส่งของ PROD
- ลด ACK ซ้ำใน endpoint เดิม และยอมให้ส่งใหม่เมื่อ endpoint เปลี่ยนหรือ process เริ่มใหม่
- ปรับข้อความ log ให้แยก รับฝากแล้ว / ส่งต่อแล้ว / ถึงปลายทางแล้ว ตามเหตุการณ์จริง

การทดสอบอีเมลลืมรหัสผ่านจริงยังต้องใช้กล่องอีเมล QA ที่รับข้อความได้ บัญชี example.invalid ไม่พิสูจน์ email delivery
