RELIO Build 31

Build 31 improves native Nearby connection diagnostics and protects an active
connection negotiation from transient app lifecycle and readiness changes.

- Preserves the exact Google Nearby connection status code, status name, and
  message through the Android plugin bridge into DEV/QA diagnostics.
- Records the connection operation, initiator/responder role, elapsed time,
  strategy, Android API, and installed Google Play Services version.
- Defers Nearby session stop/restart while a connection attempt is resolving;
  lifecycle grace remains bounded by the existing 35-second attempt timeout.
- Keeps P2P_CLUSTER, first-contact consent, identity verification, and offline
  Nearby behavior unchanged.

Physical Huawei API 29 ↔ realme API 35 retest is owner-run and is not claimed by
this build process.
