# RELIO Test v0.8.6 Build 21

This QA release hardens Android Nearby readiness across API 24 and newer:

- Selects Nearby permissions by Android SDK and reports missing requirements.
- Keeps SOS and shared-location coordinates separate from Nearby discovery.
- Detects Bluetooth capability/state and Google Play Services availability.
- Starts and recovers advertising/discovery as foreground readiness changes.
- Shows discovered real devices before RELIO identity confirmation and applies
  a bounded hello timeout so users can retry failed connections.
- Keeps chat, SOS, and Rescue on the local Nearby path without requiring
  Internet access.

Physical radio interoperability across Android versions and OEM devices still
requires the two-phone acceptance matrix. This release does not claim that
physical testing has passed.
