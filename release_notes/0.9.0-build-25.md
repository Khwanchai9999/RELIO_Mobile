Build 25 strengthens trusted Nearby identity.

- First connections continue to require an in-person authentication-code check
  and an explicit approval.
- RELIO stores a device-local signing identity in Android Keystore and pins a
  peer's public identity only after a verified challenge-response.
- A previously trusted peer may reconnect without another prompt only after
  proving the same pinned identity. Changed or blocked identities are rejected.
- Existing conversations and offline-first message behavior remain local and
  available without a RELIO cloud account.

Remote Supabase messaging, FCM delivery, and physical-device reconnect have not
been verified for this candidate. This artifact is unpublished and has not
been installed on a phone.
