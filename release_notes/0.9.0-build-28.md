RELIO Test v0.9.0 (Build 28)

- Fix the protocol-v2 first-contact identity challenge contract: an unknown
  stable target ID is valid while the authenticated Nearby endpoint is still
  being enrolled. This was the reason both Build 27 phones rejected the first
  challenge before identity proof could complete.
- Keep identity proof, consent, and key pinning mandatory. Extend the bounded
  handshake deadline to 30 seconds and retain simultaneous independent
  challenges without overwriting their nonces.
- Add structured identity-stage diagnostics, including trace ID, elapsed time,
  protocol version, redacted peer alias, failure reason, and app-requested vs
  native/remote disconnect attribution.
- Fix auto-accept for a uniquely verified, previously pinned trusted peer.
- Add paired first-contact, trusted reconnect, simultaneous challenge,
  corrupted-signature, timeout, and packet-contract tests.

Build 27 remains immutable. Build 28 is not physically verified; no phones were
modified or used for this release validation. Two-phone physical retest remains
required before claiming Nearby interoperability.
