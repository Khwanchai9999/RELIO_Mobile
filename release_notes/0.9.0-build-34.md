# RELIO Test 0.9.0+34

## Local-first reliability and accessibility

- Keeps startup available when the saved theme preference cannot be read; the
  app falls back to the system theme.
- Makes image messages open in a zoomable full-screen viewer and shows a clear
  fallback when a local image file is missing.
- Improves narrow-screen layouts at larger text sizes across Home, navigation,
  chat lists, and location cards.
- Makes concurrent duplicate incoming text, location, and media UUIDs atomic
  in SQLite so unread counts and chat rows are created only once.

Automated gates passed for this build. Native Nearby radio behavior still
requires an authorized two-phone physical test; this release does not claim
physical verification.
