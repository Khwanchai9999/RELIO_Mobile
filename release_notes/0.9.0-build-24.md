RELIO Test 0.9.0+24 — safer Nearby communication and notifications

- Adds a persistent local trust/block directory and explicit Nearby connection
  confirmation with an authentication-code comparison on both devices.
- Persists incoming-message unread counts and read times. Read receipts travel
  only to the connected peer and never include message text.
- Adds Android message/SOS notifications with private lock-screen visibility,
  generic message previews, and notification-tap routing.
- Adds opt-in QA FCM token registration for a signed-in Supabase identity.
- Keeps message delivery offline-first. Firebase is used only for Android push;
  Supabase remains the cloud backend. No PROD Firebase config or full
  App Distribution self-update SDK is included by this change.
- Adds a separate role-guarded Admin Console and RLS migration for operations
  metadata. Administrators do not receive message-content or attachment access.

No phone was modified during the build pipeline. Physical Nearby, read-receipt,
notification, and remote-push acceptance remains a separate manual check.
