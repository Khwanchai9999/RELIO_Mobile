# RELIO QA 0.9.0+43 — recovery restart guard and relay receipt acceptance

- คง Auth recovery, Thai relay log และ authenticated durable Text ACK จาก Build 40–42
- จำ recovery guard ข้ามการเปิดแอปใหม่จนกว่าตั้งรหัสผ่านสำเร็จ, Login ปกติสำเร็จ หรือ Logout เพื่อไม่ให้ recovery session เปิด Sync เอง
- เก็บเฉพาะสถานะ guard ไม่มี token/password ใน app preferences ใหม่
- ไม่เปลี่ยน schema, ownership policy, SOS, PROD routing หรือเส้นทาง Relay ที่เริ่มแล้ว
- Build 41/42 เป็น local gate candidates ที่ไม่ติดตั้ง; Build 43 ใช้สำหรับ physical acceptance สุดท้าย

การรับอีเมลและตั้งรหัสผ่านผ่านลิงก์จริงยังต้องใช้กล่องอีเมล QA ที่รับข้อความได้ บัญชี example.invalid ไม่พิสูจน์ end-to-end recovery
