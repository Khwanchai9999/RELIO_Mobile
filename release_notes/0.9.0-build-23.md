RELIO Test 0.9.0+23 — Nearby start and diagnostics fix

- Fixes Android 15 Nearby startup by declaring the normal
  `CHANGE_WIFI_STATE` permission without an API 31 cap. The real device's
  Google Nearby service returned status 8033 when the declaration was capped.
- Keeps Nearby's permission model SDK-specific: Location remains required
  through API 31; Android 12L and newer use the Bluetooth/Nearby Wi-Fi tiers
  and do not require Location for Nearby. SOS and Send Location remain separate.
- Preserves the native PlatformException code, message, details, parsed Nearby
  status, operation, readiness, service ID, strategy, active-state snapshot,
  device model/API, and retry count in developer diagnostics.
- Coalesces overlapping session starts, reconciles already-active statuses,
  recovers from out-of-order session state without disconnecting peers, and
  uses bounded exponential retry up to a five-minute interval.
- The permission card now reflects live readiness and does not offer a
  misleading runtime permission action when those permissions are already
  granted or the blocker requires an updated app.

Physical Nearby verification on Huawei STK-L22 and realme RMX3661 remains for
the user after installing this release. This pipeline does not install the APK
on either phone.
