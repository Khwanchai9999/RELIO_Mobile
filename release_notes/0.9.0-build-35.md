# RELIO Test 0.9.0+35

## Nearby transport isolation diagnostics

- Adds DEV/QA-only transport modes for the P2P_CLUSTER baseline, pausing
  discovery during negotiation, and a P2P_POINT_TO_POINT diagnostic.
- Tracks discovery epochs and endpoint freshness, invalidates lost or stale
  endpoints, and permits one bounded retry on a newly discovered endpoint
  after status 8011. Status 13 is recorded without a blind retry.
- Adds a focused Nearby transport test page and redacted connection lifecycle
  diagnostics to help compare discovery, advertising, and native negotiation
  state across attempts.

Automated tests verify RELIO state handling and mode selection only. They do
not establish physical radio behavior; authorized two-phone testing remains
deferred.
