# RELIO QA Build 45

- ปรับปรุงการบีบอัดรูปภาพในห้องแชทอัตโนมัติก่อนส่ง (ความละเอียดสูงสุด 1024×1024 px, คุณภาพ 70%) ทำงานแบบ Offline ในเครื่อง 100%
- ลดขนาดไฟล์ภาพถ่ายจาก 4–10 MB เหลือประมาณ 60–90 KB เพื่อแก้ปัญหาคอขวดและเพิ่มความเร็วในการส่งไฟล์ผ่าน Nearby / Bluetooth ทุกรุ่น (ครอบคลุม Huawei และอุปกรณ์สเปกประหยัดพลังงาน)
- ป้องกันช่องสัญญาณหลุดขณะส่งไฟล์ความเร็วต่ำ
- คงความเข้ากันได้ของระบบจัดเก็บ SQLite และความสมบูรณ์ของข้อมูลเดิมทั้งหมด
