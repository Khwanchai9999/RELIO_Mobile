# RELIO QA 0.9.0+40 — Auth recovery และ durable relay acceptance

- แก้ปุ่มลืมรหัสผ่านที่ยังไม่มี action เพิ่ม request และหน้าตั้งรหัสใหม่ผ่าน AuthService/CloudDataSource
- Android callback แยกตาม package ของแต่ละ flavor; Supabase ตรวจ token/PKCE และต้องมี recovery event ก่อนเปลี่ยนรหัส
- Recovery ยังไม่เปิด authenticated Sync จนกว่าตั้งรหัสผ่านสำเร็จ ไม่เปลี่ยน schema หรือ ownership policy
- เพิ่ม QA-only control พักเฉพาะ Text ที่เครื่องกลางรับฝาก เพื่อทดสอบ persistence และการ reconnect โดยไม่พัก SOS หรือเปลี่ยน PROD

Live Auth acceptance ต้องใช้ RELIO-QA ที่ active, callback allowlist ตรง package และกล่องอีเมลทดสอบที่รับลิงก์ได้ บัญชี example.invalid ไม่พิสูจน์ email delivery รายงานผล physical และข้อจำกัดแยกจาก automated tests
