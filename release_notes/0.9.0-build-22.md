# RELIO 0.9.0 (Build 22) — QA

- เพิ่มโลโก้ RELIO ที่ได้รับอนุมัติเป็นไอคอนแอป, adaptive icon, splash screen และหน้าเริ่มต้น
- ชื่อแอปที่แสดงใน Android เป็น RELIO ทุก flavor
- SOS แบบ guest ทำงานและบันทึกในเครื่องได้ โดยไม่ส่งเข้าคิว Cloud หรือผูกกับบัญชีที่ลงชื่อเข้าใช้ภายหลัง
- ข้อความ รูปภาพ วิดีโอ และตำแหน่งใช้ตัวตน Cloud ปัจจุบันเมื่อเข้าสู่ระบบ หรือ stable device ID เมื่อใช้งานแบบ guest
- ข้อความผิดพลาดในแชตไม่แสดง exception ดิบ และนำปุ่มโทร/เมนูที่ยังไม่รองรับออก
- ปรับปรุง Android QA updater และการแยก dependency ระหว่าง QA กับ PROD ตาม pipeline เดิม

Build 22 เป็น QA build สำหรับทดสอบซอฟต์แวร์เท่านั้น การทำงานจริงระหว่างอุปกรณ์
Nearby/Bluetooth/Wi-Fi และ OEM ยังต้องรอการทดสอบบนโทรศัพท์โดยผู้ใช้
